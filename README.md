# Flask Authentication System

A simple login and register web application built using Python Flask.

## Features

- User registration
- User login
- Session management
- Dashboard
- Logout

## Tech Stack

- Python
- Flask
- HTML
- CSS

## How to Run

Install the required packages:

```bash
pip install flask flask-session
```

Run the application:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
